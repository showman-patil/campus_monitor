## ⚙️ Backend (Django)
- **Models (optional for demo)**: Entity, Event, Prediction, Alert.
- **Views**:
- `/api/search/` → returns entities.json
- `/api/timeline/` → returns timeline.json
- `/api/predict/` → returns predictions.json
- `/api/alerts/` → returns alerts.json
- **Static JSON simulation** in `/dashboard/data/`
- **Frontend pages** load via `render()` and make JS `fetch()` calls to above APIs.
